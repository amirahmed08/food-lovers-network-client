# FoodNet - Food Review Web Application

FoodNet is a full-stack food review platform where users can explore food items, add reviews, and manage their own reviews after login. Each user can only see and manage their own reviews.

---

##  Features

-  User Authentication (Login & Register)
-  Add Food Reviews
-  View Only Your Own Reviews (Protected Route)
-  Delete Reviews
-  Star Rating System
-  Fully Responsive UI (Mobile + Desktop)
-  Real-time UI updates after actions
-  Modern UI with Tailwind CSS

---
